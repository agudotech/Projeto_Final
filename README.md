# Sistema de Análise de Vendas

## 1. Sobre o projeto

Este projeto foi desenvolvido como atividade avaliativa do curso de Desenvolvedor Python do SENAI.

O objetivo é realizar uma análise exploratória de dados de vendas, utilizando Python para identificar padrões de consumo, desempenho comercial e oportunidades de melhoria nas estratégias de negócio.

## 2. Objetivos

- Explorar e compreender a base de dados.
- Identificar e tratar dados ausentes, duplicados e inconsistentes.
- Calcular o faturamento bruto e líquido.
- Identificar os produtos e categorias mais vendidos.
- Analisar a evolução das vendas ao longo do tempo.
- Avaliar o desempenho dos vendedores.
- Investigar as formas de pagamento utilizadas.
- Comparar o desempenho comercial por estado e região.
- Criar gráficos para facilitar a interpretação dos resultados.
- Desenvolver uma análise estratégica para apoiar decisões de marketing.

## 3. Tecnologias utilizadas

- Python   
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- PyCharm

## 4. Base de dados

O projeto utiliza o arquivo `vendas.csv`, contendo registros de vendas realizadas entre 2021 e 2023.

Os dados são utilizados para calcular indicadores comerciais, gerar visualizações e investigar tendências de vendas.

## 5. Como executar

1. Abra o projeto no PyCharm.
2. Configure um interpretador Python com suporte ao Jupyter.
3. Instale as bibliotecas necessárias.
4. Verifique se o arquivo `vendas.csv` está disponível no diretório de execução.
5. Abra o notebook `analise_de_vendas.ipynb`.
6. Execute as células sequencialmente.

Para instalar as bibliotecas:

```bash
python -m pip install pandas numpy matplotlib jupyter ipykernel
```

## 6. Resultados esperados

O projeto apresenta indicadores de faturamento, classificações de produtos e vendedores, análises temporais e regionais, além de oito gráficos.

Os resultados permitem compreender melhor o desempenho das vendas e identificar oportunidades de investimento comercial.

## 7. Conclusão

A análise de dados contribui para transformar registros de vendas em informações úteis para a tomada de decisão.

Com Python, Pandas e Matplotlib, é possível organizar dados, calcular indicadores e visualizar tendências que auxiliam o planejamento estratégico de uma empresa.
